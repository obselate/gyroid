PRIVACY HARD RULE: Blocknet/BNT is a privacy coin. Never expose wallet addresses in any form (full, masked, shortened or hashed) or any per-wallet data (hashrate, shares, balances, payouts, rankings) on any public surface: websites, public APIs, news, promo, docs or logs that leave the user's machine. Public pages show pool totals only. Per-wallet stats appear only when a user enters their own address. Never print or display the operator's wallet or the Longhorn fee address anywhere, including the miner console. The miner console on the user's own machine SHOULD show the user's own address (their machine, their data). Treat any public feature that would display, rank or link wallets as a privacy leak: do not propose, design or ship it. Apply the rule to its purpose (protect other people's wallets and the operator's), not mechanically.
